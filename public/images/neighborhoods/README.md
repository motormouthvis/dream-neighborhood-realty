# Neighborhood card images

JPEGs in this folder are copied into the static site as `/images/neighborhoods/*`.

They were generated from [Lorem Picsum](https://picsum.photos) using fixed seeds so each area keeps a stable look:

- `hollywood-hills.jpg` — `https://picsum.photos/seed/dnr-hollywood/800/600.jpg`
- `silver-lake.jpg` — `https://picsum.photos/seed/dnr-silverlake/800/600.jpg`
- `santa-monica.jpg` — `https://picsum.photos/seed/dnr-santamonica/800/600.jpg`

To refresh assets (same dimensions), re-run those downloads into this directory.
